# Pods

## Description

Pods is a visual idea organization tool. Pods are Containers for an idea, a pod could represent anything, a person, group, idea. Pods have connections to other pods called relationships, relationships can represent anything, i.e. ownership pod 'Max' which represents a person owns his computer represented by another pod. pods are also containers for other pods, when you first load into the app you are placed in the "main" pod of the project, if you double click a pod (represented as an oval or rectangle) you enter that pod where you can have more pods and more relationships. pods can have relationships outside of the current pod which are represented as lines going off screen.
